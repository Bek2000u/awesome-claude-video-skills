# AI filmmaking repositories

A companion list of 74 repositories for making, editing and studying AI films. Entries were compared against the [upstream catalog snapshot](https://github.com/zhuyansen/awesome-claude-video-skills/blob/b4636b9ef9a0379137752133bd3540908074498d/data/skills.json) dated 2026-11-12.

## Suggested upstream additions

- [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) — Local FFmpeg editing skill and MCP server for cutting, captions, reframing and delivery checks. [Upstream issue](https://github.com/zhuyansen/awesome-claude-video-skills/issues/19)
- [KyaniteLabs/kinocut](https://github.com/KyaniteLabs/kinocut) — Local editing MCP server, Python client and CLI with cut assembly and quality checks. [Upstream issue](https://github.com/zhuyansen/awesome-claude-video-skills/issues/20)
- [vericontext/vibeframe](https://github.com/vericontext/vibeframe) — CLI and MCP for media generation and MP4 rendering with dry runs and a spending ceiling. [Upstream issue](https://github.com/zhuyansen/awesome-claude-video-skills/issues/21)
